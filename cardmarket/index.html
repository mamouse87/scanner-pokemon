Card Scanner → Cardmarket

1. Installa il pulsante (una volta, dal PC)

  1. Mostra la barra dei preferiti di Chrome: Ctrl+Shift+B.
  2. Se avevi già il pulsante, eliminalo (tasto destro → Elimina) e trascina di nuovo questo:

📋 Card Scanner → CM

2. Ogni set

  1. App: Lista → tocca il nome del set → scrivi l'eventuale commento → Invia file (Bluetooth, email, WhatsApp…).
  2. Cardmarket: Vendite → Inserisci carte bulk → scegli l'espansione.
  3. Premi 📋 Card Scanner → CM, scegli il file ricevuto (o incolla il testo), imposta i centesimi da aggiungere e il tuo nome utente (la prima volta), poi Compila la pagina.
  4. Prezzo = offerta più bassa in quella lingua, Near Mint o migliore, escluse le tue + i centesimi scelti. Se non riesce a leggerlo usa la tendenza e lo segnala in arancione.
  5. Righe verdi = normali, viola = Reverse, arancione = nome o rarità diversi da quanto scansionato: controllale.
  6. Premi il pulsante di invio di Cardmarket. Se il set ha 2 pagine: invia, vai alla seconda e premi di nuovo il pulsante (la lista resta caricata).

Lo script non invia nulla da solo e non legge password.

In alternativa

Se il pulsante non funziona: sulla pagina di Cardmarket premi F12 → Console, incolla il codice e premi Invio.
